     1️⃣ Ans : All of them for declaring variable. The difference between them in features.

     var can be redeclared a variable in the same name , it also can be hoisted by undefined value. 

     let can't be redeclared a variable in the same name but it allow reassign as var,
     and it doesn't allow hoisting.

     const use to declare a fixed variable, value isn't changeable and it doesn't allow hoisting or redeclaration.


     2️⃣ Ans : The spread operator is used to spread elements of an array or object into individual elements.

     3️⃣ Ans : map() run a function on each element of an array and returns a new array.

     filter() selects elements from array which matches condition and returns a new array.

     foEach() run a function for each element but returns nothing.

     4️⃣ Ans : arrow function is a syntex to write function shortly by using => and it can't be hoisted.


     5️⃣ Ans : It's a powerfull syntex for writing strings for its benefits like :
